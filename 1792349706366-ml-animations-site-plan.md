# План: Минималистичный сайт с анимациями ML

## Цель
Создать статический сайт с 4 анимациями на тему машинного обучения, разместить на GitHub Pages.

## Технологии
- HTML5, CSS3, JavaScript (ES6+)
- GSAP (GreenSock) для анимаций
- GitHub Pages для хостинга

## Структура сайта

### Файлы
```
/
├── index.html          # Главная страница
├── css/
│   └── style.css       # Стили
├── js/
│   ├── main.js         # Инициализация
│   └── animations.js   # GSAP анимации
├── assets/
│   └── (иконки, если нужны)
└── README.md           # Инструкции по деплою
```

### Содержание страницы
1. **Шапка** — заголовок "Машинное обучение в действии"
2. **Секция 1** — Нейросеть (узлы + связи)
3. **Секция 2** — Обучение модели (график функции потерь)
4. **Секция 3** — Классификация данных (точки + граница)
5. **Секция 4** — Градиентный спуск (оптимизация параметров)
6. **Подвал** — кнопка наверх, копирайт

## Анимации (GSAP)

### 1. Нейросеть
- Появление слоёв (fade + scale)
- Мерцание связей (цвет/прозрачность)
- Активация нейронов последовательно

### 2. Обучение модели
- Появление графика
- Анимация линии функции потерь (рост → спад)
- Индикатор эпох

### 3. Классификация
- Точки появляются случайным образом
- Линия границы решения рисуется
- Точки меняют цвет по классам

### 4. Градиентный спуск
- Точка на поверхности появляется
- Траектория спуска анимируется
- Стрелки градиента показывают направление

## Интерактивность
- Кнопка "Начать" для каждой анимации
- Кнопка "Следующая" для перехода между секциями
- Наверх при скролле

## CSS
- Минималистичный дизайн (белый фон, чёрный текст)
- Flex-верстка для центровки
- CSS-переменные для темы
- Без адаптива (десктоп 1200px+)

## GitHub Pages
1. Создать репозиторий
2. Добавить файлы
3. В Settings → Pages выбрать ветку main + папку / (root)
4. URL: `username.github.io/repo-name`
