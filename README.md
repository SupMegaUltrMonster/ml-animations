# ML Animations Site

Минималистичный сайт с интерактивными анимациями на тему машинного обучения.

## Содержание

Сайт содержит 4 секции с анимациями:

1. **Нейронная сеть** — визуализация работы нейрональной сети с узлами и связями
2. **Обучение модели** — анимация минимизации функции потерь
3. **Классификация данных** — разделение данных на классы с границей решений
4. **Градиентный спуск** — оптимизация параметров с визуализацией траектории

## Технологии

- HTML5, CSS3, JavaScript (ES6+)
- GSAP (GreenSock Animation Platform) для анимаций
- Canvas API для отрисовки графики

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
npx serve .
```

или

```bash
python -m http.server 8000
```

## Деплой на GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Скопируйте файлы в репозиторий
3. В настройках репозитория перейдите в Settings → Pages
4. Выберите ветку `main` и папку `/ (root)`
5. Сохраните настройки
6. Ваш сайт будет доступен по адресу `https://username.github.io/repo-name`

## Кастомизация

Цветовая схема задаётся через CSS-переменные в `css/style.css`:

- `--color-accent` — основной акцентный цвет
- `--color-bg` — цвет фона
- `--color-text` — цвет текста
